# 🎵 Loja de Discos

Site de uma loja fictícia de discos de vinil, com foco em **Música Popular Brasileira (MPB)**. Projeto feito para praticar HTML e CSS.

🔗 **Acesse o site:** https://muriloma18.github.io/loja_de_discos/

## Sobre

A loja nasceu com o propósito de valorizar o vinil e manter viva a paixão pela música. O site apresenta a proposta da loja e um catálogo com discos de grandes nomes da MPB, como Djavan, Gal Costa, Marisa Monte, Jorge Vercilo, Jorge Ben Jor e a dupla Elis Regina e Tom Jobim.

## Tecnologias usadas

- HTML5
- CSS3

## Como rodar localmente

1. Clone o repositório:
```bash
   git clone https://github.com/muriloma18/loja_de_discos.git
```
2. Abra o arquivo `index.html` no navegador.
